# Рабочая папка «КАРТА»

Этот репозиторий публикуется на GitHub Pages: <https://hainox.github.io/karta-sao/>. Каталог карт находится по адресу <https://hainox.github.io/karta-sao/hub/>.

## Опубликованные карты

- корень — дворы, участки, МНО, детские и спортивные площадки, СММ и слой урн;
- `hub/` — каталог рабочих страниц и печатных форм;
- `odh-map/` — карта ОДХ, районная разметка, приёмка изменений и выгрузки;
- `smm/` — пять типовых дворовых планировок и схемы уборки;
- `yards-print/` — печать карты дворов в форматах A3 и A1.

Основные слои карты ОДХ опубликованы в `odh-map/layers/`. Корневые `areas.geojson`, `mno.geojson`, `dp.geojson`, `sp.geojson` и снимок `urns_sao_active_snapshot.geojson` используются картой дворов. `smm.geojson` и `smm_routes.geojson` — исходные данные секции `smm/`; на корневой карте слой маршрутов СММ снят.

## Исходники и проверки

- `projects/odh-yandex-export/` — источники, скрипты подготовки данных и локальные варианты экспорта; GitHub Pages обслуживает готовые страницы и слои из `odh-map/`;
- `tests/` — проверки страниц атласа и опубликованных наборов данных; из корня: `python -m pytest tests -q`;
- `api/` — серверная часть защищённой районной разметки и приёмки.

При подготовке новых выгрузок рабочие файлы держать в соответствующем `projects/.../work`, готовые ОДХ-слои — в `odh-map/layers/`, а не складывать временные источники в корень.

Состав страниц и счётчики сверены с production 14 сентября 2026 года. Обновления в рабочей копии сами по себе не меняют опубликованный сайт.
