## Нормализация и состояния

Макет 852×1846 приведён к 390×845 CSS px с сохранением пропорций. Реализация снята браузером при ширине390/1280 CSS px, density1, full-page; сравнение — при одинаковой ширине390. Высота страницы зависит от настоящего содержания. Рабочий кабинет: доступная к изменению тестовая площадка, один обзорный кадр и один МАФ с фото. Приёмка: submitted, те же фото. Используется синтетический PNG существующей QA-площадки, а не фотография реальной площадки; все API в этих прогонах замоканы. Нет production-записей.

## История сравнения

- P2: очередь и служебные элементы отодвигали фото вниз. Исправлено: отдельное состояние карточки, компактная верхняя панель с возвратом и раскрываемым меню, фото сразу под адресом, полная ширина фото на телефоне. Подтверждено повторными снимками и composite.
- P2: системная кнопка выбора файла была меньше44px. Исправлено: минимальная высота input и file-selector-button44px. Финальный захват/измерение подтверждаются отдельным QA log.
- Functional P2: Back во время сохранения возвращал пользователя в карточку. Исправлен navigationSeq guard; regression сначала RED, затем GREEN. Проверены также Back/Forward во время reload и смена desktop/mobile.
- Functional P2: ошибка фото уже созданного МАФ должна показывать существующую карточку для дозагрузки. Для оцифровки сохранено обновление данных при ошибке, в приёмке введённая причина сохраняется. Тест подтверждает один POST, один неуспешный PUT и доступное действие дозагрузки.

## Итоговые проверки

Luna: Playwright13/13 на ширинах360/390/430/768/1280; pytest71/71 с исключением двух Linux-only backup suites, требующихfcntl. Их полный прогон выполняется Linux CI. Node syntax check и diff check проходят. На четырёх фото-сценариях capture/review ×390/1280 — 0 console/page errors, открытие обзорного фото и МАФ, закрытие viewer и возврат фокуса подтверждены. Независимое JS-ревью на Luna — без P1/P2.

## Осознанные отличия и остаточная проверка

Это реализация концепта как основы в существующем продукте, не копирование выдуманных данных макета. МАФ показаны развёрнуто для осмотра, сохраняются реальные имена файлов, удаления и серверные ограничения; в mock не переносится безусловная зелёная отметка готовности. Камера, экранная клавиатура и безопасные области на физических Android/iPhone пока не проверены; эмуляция ширины не подтверждает аппаратную проверку.
