# План: печатная схема САО по эталону

> Выполняется в текущем разрешённом пользователем рабочем репозитории.

## 1. Создать печатную страницу 1000 x 1400 мм

**Файлы:**
- Создать `odh-map/print-1000x1400.html`.

**Действия:**
1. Задать `@page` 1000 x 1400 мм без полей и контейнер листа того же размера.
2. Воссоздать шапку, основной заголовок и нижнюю правую легенду по измерениям эталона.
3. Загрузить существующие слои из `layers.json`, выделить очереди эталонными цветами и приглушить базовую карту.
4. В легенду вывести только подтверждённые для САО объекты и количества.

## 2. Переключить сценарий печати

**Файлы:**
- Изменить `odh-map/index.html`.

**Действия:**
1. Направить существующую кнопку печати на `print-1000x1400.html`.
2. Уточнить подпись кнопки: «Печать 1000 × 1400 мм».
3. Оставить `print-a1.html` без изменений.

## 3. Проверить и опубликовать

**Файлы:**
- Создать `odh-map/tests/validate_reference_print.py`.

**Действия:**
1. Проверить наличие ключевых размеров, координат легенды, цветов очередей и подтверждённых чисел.
2. Открыть страницу на локальном сервере, убедиться в загрузке карты, заголовка и легенды.
3. Проверить изменения Git, зафиксировать и отправить в `main`.
4. Дождаться успешной сборки GitHub Pages и открыть опубликованную страницу.
