# Печатная карта САО по эталону ЮВАО

## Цель

Добавить в `odh-map` отдельную печатную страницу, визуально и геометрически повторяющую композицию предоставленного образца: лист 1000 x 1400 мм, портретная ориентация, шапка, центрированный заголовок, спокойная картографическая подложка и легенда внизу справа.

## Принятый эталон

- Формат листа: 1000 x 1400 мм, портрет, без полей.
- Шапка: белая полоса 450,77 x 33,10 мм в координате 10 x 10 мм.
- Заголовок: три центрированные строки, начиная примерно с 55 мм от верхнего края.
- Легенда: координата 718,84 x 984,99 мм, размер 254,97 x 388,07 мм, фон `#D6DCE5`, чёрная рамка 0,80 мм.
- Цвета очередей: I — `#FF0000`, II — `#0000FF`, III — `#00B050`.

## Данные и границы достоверности

Страница использует только существующие слои САО из `odh-map/layers.json`: границу, очереди, склады, ПГМ, СММ, здравоохранение и гидранты. Количества берутся из опубликованного набора САО. Не добавляются маршруты роторной уборки, врезки МКД и объекты ЮВАО — их исходные данные для САО не предоставлены.

## Совместимость

- Новый файл: `odh-map/print-1000x1400.html`.
- Кнопка печати на основной странице ведёт на новый файл.
- Текущий `print-a1.html` не меняется и остаётся резервной версией A1.
- Фоновая карта OSM приглушается только CSS-фильтром; исходная подложка из PDF не копируется и не используется.
