# Хаб карт САО

Статический каталог карт для GitHub Pages. Открывает независимые карты в рабочем окне (`iframe`) и даёт ссылку на полноэкранный режим.

## Доступные направления

1. Дворы и участки САО — корневая карта сайта;
2. ОДХ и очередность — `../odh-map/`;
3. ОДХ для печати — `../odh-map/print-a3.html`.

Следующий этап: добавить общий фильтр района и обмен выбранным объектом между картами через `postMessage`.
