# Карта ОДХ САО

Публичная интерактивная карта: <https://hainox.github.io/karta-sao/odh-map/>.

## Содержание карты

- 688 уникальных объектов ОДХ: 98 в первой очереди, 318 во второй и 272 в третьей;
- граница САО и отдельная врезка Молжаниновского района;
- 215 точек привязки контейнеров ПГМ (451 контейнер), 24 кандидата на временное складирование снега и 3 сухие свалки;
- 20 подтверждённых учреждений здравоохранения и 1 адрес на уточнении;
- 402 места хранения СММ и 24 адресных центроида пожарных гидрантов.

Очередности считаются по уникальным ID ОДХ; в GeoJSON одна позиция может состоять из нескольких геометрических частей. Поэтому число объектов не равно числу GeoJSON features.

## Выгрузки

Раздел «Выгрузки» в сайдбаре карты собирает файлы прямо в браузере из уже
загруженных слоёв: сервер и вход не нужны, а числа совпадают с картой.

- `Excel: полный реестр` — книга `sao-odh-register.xlsx`: «Обзор», «На штаб»,
  «Районы» и лист на каждый слой с полными атрибутами источника;
- `Excel: таблица на штаб` — книга `sao-odh-headquarters.xlsx` из одного листа;
- `PDF: таблица на штаб` — печатная форма, из неё браузер сохраняет PDF;
- `CSV: отчёт по маршрутам` — `odh-routes-<дата>.csv` по районам: объекты, точки,
  очереди и площадь уборки.

Единица счёта — точка, то есть геометрическая часть объекта: у одной позиции ОДХ
их бывает несколько. Рядом показывается вторая единица — объекты по ID.
Колонка «Факт» считает точки, подтверждённые официальным источником, а не просто
нанесённые на карту. Разбор по районам идёт по балансодержателю; объекты «АвД САО»
и объекты без района собраны в строке «АвД САО».

Логика выгрузок вынесена в `exports.js` (`window.ODHExports`) — чистый модуль без
DOM и сети, проверяется тестом `tests/exports.spec.js`. Книгу Excel собирает
ExcelJS, подключённый с CDN.

## Районная разметка и печать

- `district-links.html` — вход по району;
- `district-editor.html` — разметка маршрутов и объектов;
- `district-review.html` — проверка и приёмка правок;
- `prefecture-guide.html` — памятка для приёмки;
- `print-a3.html` и `print-a1.html` — формы печати A3 и A1; карта также содержит отдельный лист `print-1000x1400.html`.

Правки становятся частью утверждённой карты только после проверки и приёмки. Локальный просмотр файла сам по себе ничего не публикует.

Готовые GeoJSON-слои, которые загружаются опубликованной картой, находятся в `layers/`. Исходные таблицы, рабочие материалы и код подготовки выгрузок лежат в `projects/odh-yandex-export/` и не входят в GitHub Pages.

Счётчики сверены с опубликованной интерактивной картой и слоями 14 сентября 2026 года.
