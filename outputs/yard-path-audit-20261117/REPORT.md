## Проверка возможности выбора основного направления

Исходный `/opt/sao-recovery/yard-path-source-20261116.gpkg` содержит один точечный слой, `azimuth_1`, `azimuth_2`, `all_azimuths`, `route_id`, `chainage_m` и ссылки на связанные маршруты. Линий маршрутов в GPKG нет. Поле `azimuth_1` определяет первый исходный кадр, но само по себе не доказывает, что он даёт самый длинный обзор.

В `districts/layers/*/paths.geojson` рабочей копии `/opt/sao-recovery/yard-path-stage-20261116` геометрия sourceId найдена для 6 438 точек; у 125 точек источник отсутствует. Это доступность геометрии в данной копии, а не доказательство отсутствия дорожки в реальности.

Проведён предварительный геометрический расчёт **без записи результата**: для каждого существующего азимута измерен непрерывный участок луча внутри контура соответствующего sourceId, максимум 200 м; при различии до 1 м сохранён порядок исходных кадров. Локальная метрическая аппроксимация применена только для диагностической оценки.

- 5 488 точек: найден хотя бы один обзор длиной не менее 5 м.
- 878 точек: все существующие направления дают менее 5 м внутри доступного контура.
- 72 точки: координата точки находится вне доступного контура своего sourceId.
- 125 точек: контур sourceId не найден.
- Итого 1 075 точек требуют явной маркировки ручной проверки при таком правиле. Нельзя утверждать, что автоматически определено «самое логичное» направление для всех точек.
- Для 6 366 точек с найденным контуром и расположением внутри него предварительный максимум оставляет первый кадр у 3 871 точки и выбирает другой у 2 495. Эти два числа включают группу короткого обзора; это не готовый список для публикации.

## Права и ограничения доказательств

По текущему серверному коду район получает только точки своего balance; префектура читает районный обзор; район не может поворачивать или перемещать точку; приёмка доступна префектуре. Это инспекция кода. Авторизованные запросы под всеми 16 районными учётками сейчас не выполнялись; пароли/токены не извлекались.

Живой браузерный цикл загрузки/отклонения/повторной загрузки дорожек сейчас не выполнялся. Предыдущие успешные тесты из handoff остаются результатами прежнего прогона. Новых серверных тестов не запускали, поскольку реализации не было.
