# Карта САО: обновление и состав поставки

## Готовые карты
- `sao_map_interactive.html` — интерактивная карта: слои, поиск и карточки объектов.
- `sao_map_print_a3.html` — подготовка для печати в A3, альбомная ориентация. Откройте в браузере → «Печать / PDF A3» → выберите A3 landscape.

Карты не загружают внешнюю базовую подложку: это исключает ошибку 403 при открытии локального HTML. Геоданные встроены в HTML; отображается нейтральный фон без уличной подложки.

## Гарантированная полнота первой очереди
` s ao_wave1_complete_objects.csv` (без пробелов в реальном имени: `sao_wave1_complete_objects.csv`) содержит **ровно 97 строк**:
- 94 позиции сопоставлены с геометрией ОДХ из реестра;
- 3 позиции, отсутствующие в реестре, показаны красными точками-ориентирами: площадка МЦД «Бескудниково», ТПУ «Речной вокзал», ТПУ «ЦСКА».

Эти три точки **не являются** полигонами ОДХ/ТПУ, кадастровыми или юридическими границами. Для юридической геометрии необходимы ППТ/кадастровые материалы или внутренний ГИС-источник.

## Дополнительные слои
- `sao_pgm_containers.csv` — 435 записей размещения, суммарно **451 контейнер ПГМ**. В карте 215 точек — представители привязанных геометрий ОДХ; 220 записей не сопоставлены с текущим набором ОДХ.
- `sao_snow_storage_sites.csv` — 45 адресов временного складирования снега из плана на 2025–2026 гг. Из них 27 геокодерных кандидатов нанесены на карту, 18 требуют внутренней адресной сверки. Это исторический справочный слой, не подтверждение действующего перечня 2026–2027.
- `sao_legend_audit.md` — извлечённая визуально легенда и ограничения исходной PDF-карты.

## Обновить выгрузку «оставшихся» ОДХ
Установите зависимости:
```powershell
py -3.14 -m pip install --user -r .\requirements.txt
```

Задайте учётные данные только в переменных окружения и выполните скрипт:
```powershell
$env:ODS_USERNAME = 'ваш_логин'
$env:ODS_PASSWORD = 'ваш_пароль'
py -3.14 .\sao_export_remaining.py --wave1-xlsx 'C:\путь\ОДХ первая очередь.xlsx' --output-dir .\fresh_sao_out
```

Скрипт создаст отдельные `sao_remaining_msk77.*` и `sao_remaining_wgs84.*`. Учётные данные не записываются в файлы.

## Обязательная ручная проверка
1. В `sao_wave1_match_review.csv` подтвердить четыре строки `fuzzy`.
2. В `sao_snow_storage_sites.csv` проверить 18 строк `not_found` и 27 строк `candidate` по внутреннему перечню.
3. Для слоёв гидрантов, баз ДЭУ, складов реагента, ССП МВС/МВК и медучреждений получить отдельный служебный набор адресов/координат. Их отсутствие в реестре ОДХ не означает отсутствия объектов.

## Граница округа
` s ao_boundary_wgs84.geojson` (без пробелов в реальном имени: `sao_boundary_wgs84.geojson`) — визуализационный контур САО из OpenStreetMap relation 162903. На обеих картах он включён по умолчанию, а Молжаниновский район дополнительно выделен контуром и подписью. Для юридических действий используйте официальные границы, а не этот картографический слой.

## Государственные учреждения здравоохранения: исследование
`saо_state_healthcare_research.csv` и одноимённый GeoJSON — стартовый картографический реестр кандидатов для САО, включая Молжаниновский район. Для каждой точки подготовлены отдельные ссылки поиска в Яндекс Картах, 2ГИС и Google Maps. Записи не добавлены на основную карту до подтверждения государственного статуса и адреса по официальному источнику.
