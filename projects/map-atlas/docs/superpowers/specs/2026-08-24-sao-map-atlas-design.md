# Атлас карт САО: единый интерфейс и печатные формы

**Статус:** согласовано пользователем 24.08.2026
**Область:** публичный сайт `Hainox/karta-sao`; существующие URL не удаляются.

## Цель

Сделать набор независимых карт САО визуально единым, понятным для ежедневной работы и доступным из отдельной страницы-каталога. Карта дворов получает интерфейс уровня карты ОДХ; обе темы получают отдельные печатные формы A3.

## Информационная архитектура

| URL | Назначение | Статус |
| --- | --- | --- |
| `/` | Интерактивная карта дворов, участков и городской инфраструктуры | сохраняется, обновляется дизайн |
| `/yards-print/` | Печать дворов: весь САО или выбранный район/участок | новая страница |
| `/odh-map/` | Интерактивная карта ОДХ | сохраняется, обновляется символика |
| `/odh-map/print-a3.html` | Печать ОДХ A3 | сохраняется и приводится к общему стилю |
| `/hub/` | Каталог направлений: только навигация, без `iframe` | переделывается |

Хаб разделяет плитки на два блока: **Рабочие карты** (дворы, ОДХ) и **Печатные формы** (дворы A3, ОДХ A3). Каждая плитка открывает самостоятельную страницу. Хаб не загружает карту внутри себя, поэтому карта не получает две вложенные панели управления.

## Визуальная система

Общее направление: спокойный служебный атлас — тёплый светлый фон, тёмный сине-зелёный текст, зелёный акцент, тонкие серо-голубые разделители, компактная типографика. В каждой интерактивной карте:

- верхняя панель с гербом САО, названием и актуальностью данных;
- слева — фиксированная рабочая панель: фильтры, слои, статусы, карточка объекта;
- справа — карта с ненавязчивой плашкой контекста;
- одинаковые состояния фокуса, высота контролов не менее 44 px, адаптация для мобильного экрана;
- Leaflet не показывается как элемент интерфейса; компактная обязательная атрибуция картографических данных остаётся внизу карты. Подпись Молжаниновского района поверх пользовательских слоёв не показывается.

Карта дворов сохраняет Яндекс Карты и существующие данные/фильтры. ОДХ сохраняет Leaflet и свою нейтральную подложку. Общность достигается оболочкой и контролами, не принудительной заменой картографического движка.

## Брендинг и атрибуция

Герб САО и шрифтовая оболочка входят в состав общего интерфейса всех четырёх основных страниц: интерактивные дворы, интерактивная ОДХ, печать дворов и печать ОДХ. Герб встраивается как локальный ассет или data-URI. `Century Gothic` используется только как первый вариант системного CSS-стека; файл шрифта не копируется и не публикуется без отдельной лицензии.

Подложка ОДХ использует данные OSM/CARTO. Leaflet-контрол и его подпись скрываются, но внизу карты выводится минимальная неброская строка: «© OpenStreetMap contributors · © CARTO» с рабочими ссылками на условия. Она не должна перекрывать условные знаки. Это сохраняет требования поставщиков атрибуции и снижает риск блокировки тайлов. OpenStreetMap требует читаемой атрибуции, а условия поставщика тайлов проверяются перед сменой подложки.

## Символика ОДХ

Все круглые маркеры заменяются векторными условными знаками в легенде и на карте. Линейные и полигональные геометрии ОДХ остаются своей реальной геометрией; знак появляется только у точечной геометрии или ориентировочного объекта.

| Слой | Обозначение | Цвет |
| --- | --- | --- |
| Граница САО | фиолетовый пунктирный контур | `#6a1b9a` |
| ОДХ, 1-я очередь | красный знак дороги; реальные линии/полигоны красным | `#e53935` |
| ОДХ, остальные | серый знак дороги; реальные линии/полигоны серым | `#757575` |
| Контейнеры ПГМ | оранжевый знак контейнера | `#c05600` |
| Временное складирование снега | синяя снежинка | `#039be5` |
| Государственные медучреждения | красный медицинский крест | `#c62828` |

Три ориентировочные позиции первой очереди остаются специально отмеченными красным знаком дороги с подписью в карточке «ориентировочное местоположение; не юридическая граница».

## Печать дворов

Новая страница `/yards-print/` предоставляет:

1. общий режим A3 для всей территории САО;
2. режим выбранного района;
3. режим выбранного участка выбранного района;
4. печатную легенду и данные даты выгрузки;
5. URL-параметры `district` и `section`, чтобы ссылкой открыть уже отфильтрованный вид.

В печатном CSS устанавливается `@page { size: A3 landscape }`. Пользователь выбирает нужный вид в панели, затем использует «Печать / PDF A3». Карта дворов сохраняет интерактивные слои, но печатный режим скрывает несущественные элементы управления.

## Производительность и ключ Яндекс Карт

Для GitHub Pages данные ОДХ больше не встраиваются в HTML. Каждая карта получает небольшой HTML-shell, `layers-manifest.json` и отдельные GeoJSON-файлы. Загрузка выполняется через `fetch()` с индикатором по слоям, понятной ошибкой и кнопкой повторной загрузки. Это уменьшает первый HTML-ответ и позволяет браузеру кэшировать данные. Локальный режим запускается через HTTP-сервер, а не `file://`.

Перед публикацией проверяется ограничение Яндекс Maps API key по Referer: допускается `https://hainox.github.io/*` и локальная разработка `http://localhost:*/*` при необходимости. Путь страницы (`/`, `/yards-print/`, `/hub/`) не должен требовать нового ключа, если разрешён сам домен, но это проверяется в кабинете Yandex Developer и браузерным smoke-test после деплоя.

## Связь карт

На первом этапе связь — это каталог, прямые ссылки и параметры `district`/`section`. Обмен конкретным объектом между разными движками и общая поисковая индексация не входят в этот этап: для них требуется нормализация ID и отдельный протокол `postMessage`.

## Реализация и проверки

Новые/изменяемые компоненты:

- корневой `index.html`: унифицированная оболочка карты дворов и ссылка на её печатную форму;
- `yards-print/index.html`: отдельная A3-страница;
- `projects/odh-yandex-export/scripts/build_sao_maps.py`: SVG-символы вместо круговых маркеров, общая оболочка, manifest и внешние GeoJSON-слои;
- `hub/index.html`: список ссылок, сгруппированный по рабочим и печатным картам, без `iframe`;
- локальные тесты проверяют маршруты, символы, отсутствие круговых маркеров ОДХ, разделение хаба и декларацию A3 для обеих тем.

Проверки перед публикацией: существующие тесты ОДХ, статическая проверка хаба/страницы печати, проверка ссылок атрибуции, проверка Referer ключа Яндекс Карт, ручной просмотр в браузере, затем выборочная публикация только `index.html`, `yards-print/`, `odh-map/` и `hub/`. Данные и рабочие файлы из `projects/` не публикуются.

## Ограничения

- Подложки и API карт требуют сети; полный визуальный smoke-test выполняется по HTTPS после GitHub Pages-сборки.
- Геометрии ОДХ не меняются; меняется только их визуальное представление.
- Официальные/служебные данные не добавляются без уже действующей сверки источника.
