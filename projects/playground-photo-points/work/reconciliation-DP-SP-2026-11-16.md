## Почему исходные источники различаются на 50 строк

3 042 точки импортируются из `districts/layers/*/dp_table.geojson` и `sp_table.geojson`, а не из корневых контуров. Сличение ниже — по паре `(вид, ID площадки)`, а не по геометрии; оно не доказывает актуальность объекта. Число 50 — чистая разница строк двух реестров, не 50 потерянных при синхронизации площадок.

| Вид | ID только в контурах | Строк контуров по этим ID | Контуров без ID | ID только в точках | Строк точек по этим ID | Чистая разница строк |
|---|---:|---:|---:|---:|---:|---:|
| ДП | 35 | 35 | 2 | 1 | 1 | 36 |
| СП | 15 | 15 | 0 | 1 | 1 | 14 |

Точные различия по ID и кратности строк: [contours-vs-photo-points-2026-11-16.csv](contours-vs-photo-points-2026-11-16.csv). Два контура ДП без ID: Правды ул. 11 (Беговой); Дмитровское шоссе 27 к.2, 27 к.3, 27 к.4 (Тимирязевский). Их нельзя считать сопоставленными по ID.

На листе «Сверка» визуально подтверждено отображение снимков.

Все 209 строк листа «Снятые» прочитаны обратно и совпали с выгрузкой базы. Проверки: 380 passed, 0 failed, 5 skipped; отдельный набор ДП/СП и шаблона — 10 passed.
