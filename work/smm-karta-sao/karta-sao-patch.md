## Вставка 1 — регистрация слоя

Найти `const LAYER_CONFIG = {` (около строки 252) и добавить последнюю строку:

```js
const LAYER_CONFIG = {
  areas: { label: 'Районы и участки', file: 'areas.geojson', color: '#808080', enabled: true },
  mno:   { label: 'МНО',              file: 'mno.geojson',   color: '#e67e22', enabled: false },
  dp:    { label: 'Детские площадки', file: 'dp.geojson',    color: '#2e86de', enabled: false },
  sp:    { label: 'Спортивные площадки', file: 'sp.geojson', color: '#27ae60', enabled: false },
  smm:   { label: 'Маршруты СММ (зимняя уборка)', file: 'smm.geojson', color: '#C00000', enabled: false }   // ← НОВОЕ
};
```

Больше ничего трогать не нужно: загрузка, фильтрация по району и участку,
чекбоксы слоёв и легенда работают по этой же конфигурации автоматически.

## Вставка 3 — кнопка «Подробно» в карточке объекта

В функции, которая рендерит карточку объекта по клику (блок «Карточка объекта»),
после вывода свойств добавить:

```js
// ← НОВОЕ: кнопка «Подробно» для объектов слоя СММ
if (layerKey === 'smm' && properties.detail) {
  html += '<a class="detail-btn" href="' + escapeHtml(properties.detail) + '">'
        + 'ⓘ Подробно: схема маршрута и направление сопла</a>';
}
```

И стиль (в `<style>`):

```css
.detail-btn{
  display:block; margin-top:12px; padding:10px 14px; text-align:center;
  background:#C00000; color:#fff; border-radius:6px; text-decoration:none;
  font-weight:600; font-size:13px;
}
.detail-btn:hover{ background:#a30000; }
```

Свойство `detail` уже прописано в `smm.geojson` для каждого объекта
(`smm/#dt1`, `smm/#dt2`, `smm/#dt3`), поэтому кнопка открывает модуль
сразу на нужном дворе.

## Проверка после вставки

1. Открыть карту, включить слой «Маршруты СММ» — должны появиться три объекта
   в районах Сокол, Восточное Дегунино, Бескудниковский.
2. Фильтр «Район» → «Сокол» — остаётся только ДТ-1.
3. Клик по объекту → в карточке появляются свойства и красная кнопка «Подробно».
4. Клик по кнопке → открывается `smm/` с уже выбранным двором.
5. В модуле кнопка «ⓘ Подробно» в шапке открывает выезжающую панель;
   ссылки «→» внутри страницы открывают её сразу на нужном разделе.

## Почему выбрана именно такая архитектура

**Слой в общей карте** отвечает на вопрос «где и сколько»: район, участок,
принадлежность. Он переиспользует уже готовую фильтрацию атласа, легенду
и печать в A3 — дописывать под него ничего не надо.

**Отдельный модуль** отвечает на вопрос «как работать»: маршрут из пяти проходов
с шагом 0,55 м, вектор струи и точки приземления — это масштаб 1:200–1:500.
На карте округа такая графика физически нечитаема, растянуть её слоем нельзя.

Связка между ними односторонняя и простая: карточка объекта → кнопка «Подробно»
→ модуль на нужном якоре. Обратно — ссылка в шапке модуля.
